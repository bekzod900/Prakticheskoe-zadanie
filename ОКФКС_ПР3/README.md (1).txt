# Практическая работа №3
## Устранение последствий заражения вирусом-шифровальщиком

Учебный проект для безопасной имитации инцидента с вирусом-шифровальщиком.

> ВАЖНО: проект не содержит настоящего вируса, не шифрует содержимое файлов,
> не изменяет системные настройки и не запускает файлы из папки `Temp`.
> Все операции выполняются только внутри папки `Учебный_стенд` на рабочем столе.

## Структура проекта

- `src/create_lab.py` — создаёт учебный стенд, резервную копию и имитацию зашифрованных файлов.
- `src/restore_lab.py` — удаляет безвредные файлы-заглушки и восстанавливает исходные документы из резервной копии.
- `report/Отчет.md` — готовая основа отчёта с описанием этапов, таблицей диагностики и выводами.
- `screenshots/` — сюда добавьте собственные скриншоты выполнения работы.

## Требования

- Windows, macOS или Linux с установленным Python 3.
- Дополнительные библиотеки не требуются.

## Запуск

Из корневой папки проекта:

```bash
python src/create_lab.py
```

Скрипт создаст на рабочем столе папку `Учебный_стенд` с каталогами:
`Мои_документы`, `backup`, `Temp` и файлом `README_DECRYPT.txt`.

После изучения структуры стенда выполните диагностические действия по методичке.
Команды `msconfig`, `netstat -an`, `sfc /scannow` относятся к проверке вашей ОС:
их результаты нужно записать по факту, не копируя вымышленные значения.

Для восстановления после диагностики запустите:

```bash
python src/restore_lab.py
```

Скрипт восстановления работает только с ожидаемой папкой `Учебный_стенд` на рабочем столе.
Он удалит только три созданные проектом пустые заглушки из `Temp` и восстановит файлы
из `backup` в `Мои_документы`.

## Перед публикацией на GitHub

1. Выполните скрипты на своём компьютере.
2. Сделайте скриншоты папок до и после восстановления.
3. Заполните в `report/Отчет.md` результаты реальных проверок и добавьте скриншоты.
4. Загрузите всю папку проекта в свой репозиторий.
