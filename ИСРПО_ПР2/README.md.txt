# Практическая работа №2
## Аудит готового клиент-серверного приложения

В проекте находятся три программы:

- `server.py` — запускает TCP- и UDP-серверы.
- `client.py` — отправляет данные о погоде по TCP и UDP.
- `format_check.py` — сравнивает представление данных в JSON и XML.

## Запуск

Требуется Python 3. Откройте терминал в папке проекта.

1. В первом терминале выполните:
   `python server.py`
2. Не закрывая сервер, откройте второй терминал и выполните:
   `python client.py`
3. Для сравнения форматов выполните:
   `python format_check.py`

Если команда `python` не работает в Windows, попробуйте `py`.

## Важно
Для отчёта необходимо самостоятельно запустить программы, сделать скриншоты окон сервера и клиента и записать фактические результаты четырёх проверок.
